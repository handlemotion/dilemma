# Contributing

Thanks for looking. Dilemma is early and I'm the only one working on it, so the repo only takes pull requests from collaborators for now. That will change once the basics settle.

Issues are open, and bug reports help the most. If a character doesn't load or looks wrong, say what you expected and attach the file if you can share it, or tell me where it came from (Mixamo, a Khronos sample, your own rig out of Maya or Blender). Feature ideas are welcome too, but the order of the work comes from what our animators at Chow Mein need next, so an idea may sit for a while.

If you want to read or run the code, the README has the setup and `AGENTS.md` has the rules every change follows, for people and coding agents alike. Code you contribute is licensed AGPL-3.0-only, the same as the rest of the project.
